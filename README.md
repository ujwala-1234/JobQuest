# JobQuest – Smart Job Application Tracker

JobQuest is a Python-based console application designed to help users manage and track their job applications in one place.

The application allows users to add, view, search, update, and delete job applications. It also provides job search analytics and stores application data using a JSON file.

## Features

- Add new job applications
- View all job applications
- Search applications by company name
- Update application status
- Delete job applications
- View job search analytics
- Calculate selection rate
- Automatically record the application date
- Store data using JSON
- Handle missing or invalid JSON files

## Application Status

Job applications can be tracked using the following statuses:

- Applied
- Online Assessment
- Interview
- Selected
- Rejected

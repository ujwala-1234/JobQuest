JOBQUEST - SMART JOB APPLICATION TRACKER

How to run:
1. Extract the ZIP file.
2. Open the JobQuest folder in VS Code.
3. Open the terminal in that folder.
4. Run: python main.py

Features:
- Add job applications
- View applications
- Search applications
- Update application status
- Delete applications
- Job search analytics
- JSON file storage

Main Python concepts:
- Variables and data types
- Conditions and loops
- Functions
- Lists and dictionaries
- Modules
- OOP
- Exception handling
- File handling
- Date and time
